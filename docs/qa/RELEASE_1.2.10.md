# Проверка выпуска CamWork Translate 1.2.10

Включены исправления и отказные сценарии из [плана 1.2.9](RELEASE_1.2.9.md).
Тег 1.2.9 сохранён: публикацию остановила проверка на macOS ARM64,
обнаружившая JNA 5.4.0 без совместимой нативной библиотеки.

JNA и JNA Platform обновлены согласованно до 5.19.1. Перед публикацией:

- выполняются все тесты на Windows, Linux и macOS ARM64;
- сохраняется проверка реальной записи структуры POINT, без исключения macOS;
- проверяются ресурсы JNA для Windows x64, Linux x64, macOS x64 и ARM64;
- упакованные Windows EXE и оба macOS-пакета загружают JNA и проверяют запись
  и чтение нативной памяти перед проверкой штатных плагинов и живого перевода;
- маркер CAMWORK_PACKAGED_SMOKE_OK содержит версию JNA и архитектуру;
- публикация зависит от успеха всех проверок и всех нативных сборок.

Контрольные суммы находятся в SHA256SUMS.txt. Наборы данных для проверки
изолированы от пользовательских настроек и ключей. Режим подписи macOS
и ограничения проверки реальных клиентских окружений описаны в плане 1.2.9.
