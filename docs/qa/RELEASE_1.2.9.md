# Проверка выпуска CamWork Translate 1.2.9

Выпуск исправляет 19 дефектов, найденных независимым аудитом ядра, плагинов и интерфейса,
и воспроизводимые причины остановки перевода до перезапуска. Проверки используют отдельные
каталоги данных и фиктивные ответы провайдеров; пользовательские ключи не требуются.

## Отказы и восстановление

- Очистка истории во время запроса не позволяет позднему ответу вернуть удалённые записи.
- Параллельные MAIN и Shift сохраняют обе записи; дополнительный вывод обновляет запись по ID.
- Отмена старого запроса не выключает индикатор нового, отмена обратного перевода не теряет основной.
- Медленный диск ограничен дедлайном; повторная запись восстанавливает сохранение в том же объекте.
- Неподтверждённая физическая очистка истории явно сообщается пользователю.
- Проверяются 2000 быстрых изменений ввода, 150 параллельных обновлений истории и 100 завершений без UI.
- После исключений, отмены и таймаута обработчик принимает следующие события.
- После обрыва и таймаута CIO выполняет следующие запросы при лимите одного соединения.
- 240 HTTP-запросов и 200 AI-запросов проверяют изоляцию отказов и продолжение работы.
- Потерянный keyRelease восстанавливается по состоянию Windows; физически удерживаемая клавиша остаётся защищена.
- Языки сохраняются при обновлении сервисов, фильтров и запоздалом ответе предыдущего языка.
- LIVE продолжает работу после ошибки OCR, потерянного завершения, паузы и временного отказа перевода.
- Изменение числа, знака или отрицания не теряется как повтор субтитра.
- Проверяется реальная конкурентная пауза при заблокированном захвате без взаимной блокировки EDT.

## Плагины и сеть

- Manifest, совместимость и SHA-256 проверяются до создания экземпляра изменённого плагина.
- Установка использует временный файл, стабильное имя по ID и откат при отказе.
- Удаление закрывает жизненный цикл, HTTP и загрузчик; ошибка удаления возвращается пользователю.
- Очистка удаляет настройки и секреты без создания второго DataStore того же файла.
- Конкурентные подтверждение и удаление плагина сериализованы и идемпотентны.
- Сквозная проверка HTTP/CONNECT/TLS/redirect требует пароль прокси в CONNECT и его отсутствие внутри TLS.
- Ответ AI с незавершённой генерацией не может использоваться для автоматической замены.
- Временная некорректная страница Google не вызывает прежнюю 15-минутную блокировку маршрутов.

## Выпуск

Перед публикацией конвейер Release выполняет build/test на Windows, Linux и macOS.
Windows-пакет проверяется запуском нативного EXE и переводом контрольной фразы через host pipeline.
macOS-пакеты проверяются на собственных архитектурах; режим подписи определяется имеющимися
Apple-учётными данными. При отсутствии Developer ID пакеты явно помечены как внутренние unsigned.

Контрольные суммы публикуются в SHA256SUMS.txt. Бинарные файлы и тестовые хранилища в Git не добавляются.
Проверка автоматических сценариев не заменяет измерения конкретного клиентского окружения:
Windows UI Automation, сочетания с другими программами и все внешние платные API требуют отдельного прогона.
