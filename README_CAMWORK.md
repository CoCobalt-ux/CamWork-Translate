# CamWork Translate 1.2.5

Быстрый настольный переводчик для моделей CamWork на Windows 10/11.

## Быстрый перевод выделенного текста

1. Выделите текст мышью или комбинацией `Ctrl+A` в браузере или другом приложении.
2. Коротко нажмите и отпустите `Shift` (клавишу можно заменить в разделе
   «Настройки → Клавиатура → Быстрый перевод и замена»).
3. Русский или украинский текст переводится в выбранный язык и заменяется в том же поле. Если
   выделить полученный иностранный текст и ещё раз нажать `Shift`, он переводится обратно на язык
   модели и также заменяется в том же поле. Например: `Привет` → `Hello` → `Привет`.

Перед исходящим Shift-переводом приложение локально исправляет только частые опечатки из явного
безопасного списка: например, `Привев` превращается в корректный перевод `Hello`. Имена,
неизвестные и похожие корректные слова не изменяются. Коррекция не создаёт отдельный сетевой запрос.

Во время запроса возле курсора отображается компактный индикатор перевода. Успех и ошибка
показываются ненавязчиво и автоматически скрываются. Основное окно не открывается и не забирает
фокус.

Состояние значка в трее управляет только автоматическим показом перевода выделенного текста и не
отключает Shift-замену:

- зелёный режим: опубликованный иностранный текст сразу переводится в пассивном окне на язык
  модели; в редактируемом поле автоматическое окно не появляется, возле выделения доступна
  мини-кнопка;
- серый режим: автоматическое окно не появляется ни над опубликованным текстом, ни в поле ввода;
  возле выделения появляется мини-кнопка для явного перевода;
- если тип поверхности определить нельзя, используется безопасный вариант с мини-кнопкой без
  автоматического окна.

Обычные Chrome/Edge/Yandex определяются через Windows UI Automation. Для AdsPower/SunBrowser,
который запускается с принудительно отключённой accessibility, используется резервный
обезличенный признак формата копирования: опубликованный Chromium DOM содержит HTML, а обычные
`input`/`textarea` — только текст. Явный `contenteditable`, `role=textbox` и нативные поля ввода
получают только мини-кнопку, если Chromium сохранил editable-маркер в скопированном фрагменте.
Сам выделенный текст и HTML в журнал не записываются. Проверенный AdsPower очищает маркеры
`contenteditable`/`role=textbox`, поэтому такой rich-text редактор технически неотличим от
опубликованного DOM; для абсолютно строгого различения в этом профиле нужно убрать
`--disable-renderer-accessibility` или использовать браузерное расширение.

Мини-кнопка показывает перевод, не заменяя набираемый текст. Короткий `Shift` независимо от
состояния трея переводит и заменяет выделение в обоих направлениях. Пункт «Перевод выделенного
текста» и одиночный левый клик по значку в трее переключают только автоматический режим. Активное
состояние отмечено зелёным индикатором на цветной иконке, выключенное — нейтральной серой иконкой.
Двойной клик открывает основное окно, правый — системное меню приложения.

Перед чтением выделения приложение ожидает полного отпускания физических `Shift`, `Ctrl`, `Alt`
и клавиши Windows. Поэтому внутренний `Ctrl+C` не превращается в браузерный `Ctrl+Shift+C` и не
открывает DevTools/инспектор на Stripchat, Chrome и других сайтах. Синтетические `Ctrl/Cmd+C` и
`Ctrl/Cmd+V` гарантированно отпускают модификатор даже при ошибке; временный clipboard не
восстанавливается поверх нового пользовательского копирования.

Старая функция автоматического перевода текста в основном окне называется «Переводить при вводе
в приложении» и находится в расширенных настройках.

Готовый перевод можно безопасно вставить до 35 секунд после выделения, поэтому длинный текст не
теряется на медленном ответе. `Win+Shift+S`, `Print Screen`,
`Shift+буква`, удержание Shift и действия мышью с зажатым Shift игнорируются. Во время выбора
области снимка приложение не меняет clipboard; ожидающий Shift-перевод и вставка отменяются,
а готовый системный снимок не перезаписывается отложенным восстановлением текста.
Резервная горячая клавиша — `Ctrl+Q`.

## Переводчики

- Google Translate выбран по умолчанию и работает без ключа через цепочку совместимых
  веб-интерфейсов. Неработающий маршрут временно исключается автоматически.
- Длинный текст делится по границам предложений и переводится двумя параллельными запросами.
- Необязательная проверка орфографии выключена по умолчанию, чтобы не тратить лимит Google и не
  замедлять основной перевод.
- Если активный сервис отказал, приложение без повторов пробует доступные Google, Bing и DeepL.
  Тайм-аут каждого провайдера увеличивается только для действительно длинного текста, поэтому
  короткий запрос быстро переходит к следующему резерву, а большой не обрывается преждевременно.
- На чистой установке включены только Google, Bing и DeepL. Yandex Web, Reverso, MyMemory, Mozhi,
  LibreTranslate и остальные менее эффективные плагины установлены, но отключены; их можно
  включить вручную в настройках.
- Для официальных Google Cloud и DeepL API можно указать собственные ключи в настройках плагина.

Неофициальные бесплатные веб-интерфейсы могут измениться или ограничить частоту запросов.
Текст отправляется выбранному сервису перевода; не переводите через облачный сервис данные,
которые нельзя передавать третьим лицам.

## Установка

Запустите `CamWork-Translate-1.2.5-Setup-windows-x64.exe`. Установщик не требует прав
администратора, создаёт ярлык в меню «Пуск» и по желанию — на рабочем столе. Обновление поверх
предыдущей версии сохраняет настройки, историю, журналы и дополнительные плагины.

Переносимый архив `CamWork-Translate-1.2.5-windows-x64.zip` остаётся доступен как запасной
вариант: распакуйте его в отдельную доступную для записи папку и запустите
`CamWork Translate.exe`.

Текущая сборка не подписана коммерческим code-signing сертификатом, поэтому Windows может
показать «Неизвестный издатель» или предупреждение SmartScreen. Подлинность файла проверяется по
опубликованной SHA-256 сумме; для удаления этого предупреждения потребуется сертификат подписи
кода на CamWork.club.

Сайт и поддержка: https://camwork.club

## Сборка Windows x64

Нужны JDK 17, JDK 21 и Inno Setup 6. JDK 17 формирует встроенный runtime, JDK 21 компилирует
приложение. Безопасный сборщик создаёт в `build/release` единый установщик EXE, переносимый
Windows-архив и SHA-256 суммы. Java входит в оба варианта:

```powershell
.\scripts\build-windows-release.ps1 -Version 1.2.5 -JavaHome $env:JAVA_HOME -Jdk21Home 'C:\path\to\jdk-21'
```

## Сборка macOS x64/arm64

Для macOS подготовлен отдельный сценарий, который на самом Mac создаёт
самодостаточные `.app`, DMG и опциональный PKG со встроенной Java. Сборка с
Windows невозможна. До выдачи macOS-версии моделям обязательны проверка системных
разрешений и QA замены выделения в реальных Chrome/Telegram. На macOS используется
best-effort-классификация по HTML/editable-маркерам clipboard с безопасной
мини-кнопкой для обычного текста; нативного Accessibility-паритета с Windows UI
Automation пока нет.

Требования, команды для x64/arm64, Developer ID, notarization и полный чек-лист:
[docs/MACOS_BUILD.md](docs/MACOS_BUILD.md).

Свежие неподписанные DMG для внутреннего теста доступны в
[macOS QA (unsigned)](https://github.com/CoCobalt-ux/CamWork-Translate/actions/workflows/macos-qa.yml):
выберите последний зелёный запуск и скачайте artifact `arm64` для Apple Silicon или `x64` для
Intel. Артефакты хранятся 14 дней и не предназначены для выдачи моделям как production-релиз.
