CAMWORK TRANSLATE — УСТАНОВКА QA-ВЕРСИИ НА macOS

Эта внутренняя тестовая сборка подписана технической ad-hoc подписью и не
нотариализована Apple. Устанавливайте её только из официального репозитория
CamWork Translate и только после проверки контрольной суммы SHA-256.

1. Выберите сборку для своего Mac:
   - arm64 — Apple Silicon: M1, M2, M3, M4, M5 и новее;
   - x64 — Mac с процессором Intel.

2. Откройте DMG и перетащите «CamWork Translate» в папку Applications.

3. Откройте приложение из Applications. macOS предупредит, что разработчик
   не зарегистрирован в Apple. Закройте предупреждение кнопкой «Готово».

4. В течение часа откройте:
   System Settings → Privacy & Security → Security → Open Anyway.
   Подтвердите запуск паролем или Touch ID.

5. Разрешите CamWork Translate необходимые возможности:
   - Privacy & Security → Accessibility — замена выделенного текста;
   - Privacy & Security → Input Monitoring — глобальная горячая клавиша;
   - Privacy & Security → Screen & System Audio Recording — OCR и LIVE-перевод.

6. После изменения разрешений полностью завершите приложение через Cmd+Q и
   запустите его снова из Applications.

Не отключайте Gatekeeper целиком. Если macOS сообщает, что файл повреждён,
не запускайте его: скачайте пакет заново, проверьте SHA-256 и сообщите разработчику.

QA-сборка предназначена для внутреннего тестирования. Публичная версия должна
быть подписана Apple Developer ID и нотариализована Apple.
